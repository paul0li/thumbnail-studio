# 0004 — The host is the user

**Status:** Accepted · 2026-10-27

## Context

The person who builds the thumbnail every day is the show's host, from a
phone. They did not build the app and should not need to know how it works.

## Decision

Ease wins over flexibility. Every screen must make sense without explanation,
and a control only someone who knows the internals would use does not belong on
the main screen. App copy is in Spanish, the user's language.

## Consequences

Some fine adjustments are left out or tucked away.

## What would reverse it

Someone else becoming the main user and wanting more control.
